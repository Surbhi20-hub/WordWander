# WordWander 🌍📖

WordWander is a foreign language learning quiz platform built to help users test and track their language skills through interactive quizzes.

## Features

- **User Registration & Login** — Secure signup and authentication system
- **Quiz Authoring** — Create and manage custom quizzes for different languages
- **Automated Scoring** — Instant, automatic grading of quiz attempts
- **Progress Reporting** — Track performance and learning progress over time

## Tech Stack

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript

## Project Type

Individual project — also delivered as a capstone project during a Web Development internship at NetLeap IT Training and Solutions.

## Getting Started

### Prerequisites
- PHP (7.4 or higher recommended)
- MySQL
- A local server environment (e.g. XAMPP / WAMP / MAMP)

### Installation
1. Clone the repository
   ```bash
   git clone https://github.com/your-username/wordwander.git
   ```
2. Move the project folder into your server's root directory (e.g. `htdocs` for XAMPP)
3. Import the provided SQL file into MySQL to set up the database
4. Update database credentials in the config file
5. Start your local server and open the project in your browser

## Usage

1. Register a new account or log in
2. Browse or create quizzes
3. Attempt quizzes and get instantly scored
4. View your progress report to track improvement over time
